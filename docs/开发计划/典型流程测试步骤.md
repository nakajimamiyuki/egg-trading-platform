# 蛋品交易平台 典型流程测试步骤（人工验收用）

测试地址：http://localhost:8080
测试前准备：在终端执行以下命令，把环境重置到干净的演示状态

```bash
docker compose down -v && docker compose up -d
# 等约 20 秒后执行（Windows 用 demo_seed.ps1）：
bash scripts/demo_seed.sh
```

账号：admin/admin123（管理员）｜ business01/123456（业务）｜ finance01/123456（财务）｜ farm001/123456（养殖）｜ buyer001/123456（采购）

> 用法：按顺序执行，每步核对"预期结果"。不符合就记在最后的问题记录表里。

---

## 流程一：企业入驻（注册 → 审核 → 入驻合同）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 退出登录 → 登录页点"企业自助注册" → 选"养殖企业"，填账号 `testfarm01`、密码 `123456`、企业名"测试养鸡场"、养殖信息，上传 1 张证照图片 → 提交 | 提示"注册成功，待平台审核" |
| 1.2 | 用 `testfarm01` 登录 → 看首页 | 准入状态显示"审核中" |
| 1.3 | 换 `business01` 登录 → 审批中心 | 待办里有"企业准入审批： 测试养鸡场" |
| 1.4 | 点"通过" | 提示审批完成，待办消失 |
| 1.5 | 换 `testfarm01` → 首页和"我的企业" | 状态变"已通过"，出现合作评价 |
| 1.6 | 左侧"合同管理" | 有一份**入驻合同**（系统自动生成），状态"待审批" |
| 1.7 | business01 → 审批中心，通过合同签署审批（业务→财务两级，第二级换 finance01） | 合同状态变"签署中" |
| 1.8 | 合同管理 → 点"查看" | 新标签页打开合同原文，甲乙方、条款完整 |
| 1.9 | business01 点"在线签署"；再换 testfarm01 点"在线签署" | 第一次提示"待另一方签署"，第二次提示"双方签署完成，合同生效并存证" |

## 流程二：建仓入库（仓库 → 租赁审批 → 监控确权 → 交割仓 → 自动上架）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 2.1 | `farm001` → 我的仓库 → 登记仓库：名称"测试2号仓"、地址、容量 3000 | 列表出现新仓库，租赁状态"未租赁" |
| 2.2 | `business01` → 仓库管理 → 找到"测试2号仓" → 发起租赁审批，租金 6000 | 提示已发起（业务→财务两级） |
| 2.3 | business01 审批中心通过第一级；finance01 通过第二级 | 仓库租赁状态变"已租赁"，显示租金 6000 |
| 2.4 | farm001 → 我的仓库 → 监控设备 → 登记设备（名称"2号仓摄像头"、RTSP、随便填个 rtsp:// 地址）→ 点"在线检测" | 设备状态变"在线" |
| 2.5 | business01 → 仓库管理 → 设备管理 → 对该设备点"确权" | 设备"已确权"，仓库监控变"已确权" |
| 2.6 | farm001 → 产蛋录入：今天、3000 枚、A 级、50kg/件 | 列表出现录入记录 |
| 2.7 | business01 → 仓库管理 → "测试2号仓"点"建交割仓"：数量 3000、A 级、S50、**单价 5.5** → 审批中心通过 | 提示审批已发起；通过后交割仓建立 |
| 2.8 | farm001 → 交割仓一览 | 看到 DW 开头的交割仓，状态"在库"，在库 0 天 |
| 2.9 | farm001 → 库存查询 | 3000 枚 A 级，可用 3000 |
| 2.10 | buyer001 → 商品大厅 | **自动出现**该批鸡蛋卡片：A 级、¥5.5、库存 3000、来源"绿源蛋鸡养殖场" |
| 2.11 | business01 → 货架管理 → 对该商品"改价"为 5.8；再点"下架"→ 回商品大厅确认消失 → 再"上架" | 价格即时生效；下架后客户端看不到 |

## 流程三：模式①完整交易（核心流程，重点测）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.1 | `buyer001` → 商品大厅 → 点"采购"：数量 1000、模式① → 提交 | 提示"待业务审核"，页面跳到订单详情，状态"业务审核中" |
| 3.2 | 订单详情核对金额 | 总额 ¥5800（1000×5.8）、定金 ¥1160、垫资 ¥4640 |
| 3.3 | `business01` → 审批中心 → 通过订单审核 | 订单状态变"待付定金"；同时**自动生成销售合同**（合同管理可见） |
| 3.4 | `buyer001` → 订单详情 → 点"支付定金"并确认 | 提示支付成功 ¥1160；状态变"定金已付" |
| 3.5 | farm001 → 库存查询 | 总库存 3000、**锁定 1000**、可用 2000 |
| 3.6 | `finance01` → 审批中心 → 通过"垫资审批（80%)" | 订单变"平台已垫资80%" |
| 3.7 | farm001 → 消息/站内信 | 收到"垫资到账"通知 |
| 3.8 | `business01` → 订单详情 → "开具出库单"：车牌"豫A12345"、司机"王五"、电话 | 状态变"装车核验中"，出现出库单区块 |
| 3.9 | 订单详情 → 上传一张装车照片 | 附件区出现"照片（已水印）" |
| 3.10 | **三方确认**：farm001 登录点"养殖户确认"；buyer001 点"客户确认"；business01 点"平台确认" | 确认标签逐个点亮，第三个确认后状态变"出库单已确认" |
| 3.11 | `buyer001` → 点"支付尾款" | 支付 ¥4640，状态变"尾款已付" |
| 3.12 | `finance01` → 审批中心 → 通过"尾款结算审批（20%)" | 状态变"养殖户已收全款（待放行）"；farm001 收到尾款到账通知 |
| 3.13 | `farm001` → 订单详情 | 出现**电子提货凭证二维码** |
| 3.14 | 复制二维码下方那串内容（EGGPICKUP:...），粘贴到输入框 → 点"核销放行" | 提示"核销成功，放行！"，订单变"已完成" |
| 3.15 | 再点一次"核销放行"（重复扫码） | 提示"该凭证已核销"（不重复扣库存） |
| 3.16 | farm001 → 库存查询 | 库存 2000、锁定 0 |
| 3.17 | finance01 → 账单中心 | 该单"已结清"；订单详情底部资金流水：收 1160+4640 = 付 4640+1160 |
| 3.18 | farm001 → 交割仓一览 | 该交割仓状态"已售" |

## 流程五：平仓风控

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 5.1 | `farm001` → 平仓风控 → 对一个在库交割仓点"发起申请" → 选"申请退仓"、填说明 | 提示已提交 |
| 5.2 | `business01` → 审批中心通过该申请 | 交割仓变"已退仓"，对应库存退回（库存查询对应品级减少） |
| 5.3 | business01 → 仓库管理再造一个交割仓（参考流程二，数量 500、单价 4.5）→ 平仓风控 → 点"强制平仓"并确认 | 提示折价结算金额（500×4.5×80% = ¥1800） |
| 5.4 | `finance01` → 审批中心通过"平仓退款审批" | 平仓台账出现记录：原价 2250、结算 1800、盈亏 -450，状态"已退款" |
| 5.5 | farm001 → 站内信 | 收到"平仓完成"通知 |
