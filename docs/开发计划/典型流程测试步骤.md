# 蛋品交易平台 典型流程测试步骤（详细版）

测试地址：**http://localhost:8080**
建议浏览器：Chrome / Edge / Safari 均可

## 测试前准备（只做一次）

打开"终端"（Mac 按 Command+空格 搜"终端"），`cd` 到项目文件夹后依次执行：

```bash
docker compose down -v
docker compose up -d
# 等 20 秒（让服务启动完），再执行：
bash scripts/demo_seed.sh
```

看到"演示数据初始化完成 ✅"即准备完毕。

# 流程一：企业入驻

**目标：验证新企业能自助注册，平台审核通过后自动产生入驻合同并完成双方签署**

### 1.1 新企业自助注册

1. 打开 http://localhost:8080，在登录页点击下方"没有账号？企业自助注册"
2. "企业类型"选择 **养殖企业**
3. 账号信息区填写：
   - 用户名：`testfarm01`
   - 密码：`123456`
   - 联系人：`王测试`
   - 手机号：`13800000099`
4. 企业信息区填写：
   - 企业名称：`测试养鸡场`
   - 信用代码：`91410100TEST0001`
   - 法人代表：`王测试`
   - 地址：`河南省周口市`
5. 养殖信息区填写：养殖品种 `罗曼粉`、存栏量 `80000`、日龄 `200`、日均产蛋 `75000`
6. 证照上传区：在"营业执照"一行点"选择文件"，随便选电脑上的一张图片（jpg/png），等出现"✓ 已上传"
7. 点底部"提交注册（待平台审核）"
8. ✅ **预期**：绿色提示"注册成功，请等待平台审核"，跳回登录页

### 1.2 查看自己的审核状态

1. 用 `testfarm01 / 123456` 登录
2. ✅ **预期**：首页"企业准入状态"卡片显示黄色"审核中"

### 1.3 业务员审核通过

1. 退出，用 `business01 / 123456` 登录
2. 点左侧菜单"审批中心"
3. ✅ **预期**：列表第一行是"企业准入审批： 测试养鸡场"
4. 点该行右侧绿色"通过"按钮 → 弹窗里填意见"资料齐全" → 点"确认"
5. ✅ **预期**：提示"审批完成"，该条从待办消失

### 1.4 确认准入结果

1. 退出，重新用 `testfarm01 / 123456` 登录
2. ✅ **预期**：首页状态变绿色"已通过"，并显示合作评价"准入审批通过，初始合作评价：良好"
3. 点左侧"我的企业"，核对刚才填的信息都在

### 1.5 入驻合同审批与签署

1. testfarm01 点左侧"合同管理"
2. ✅ **预期**：有一份 HT 开头的"入驻合同"，状态"待审批"
3. 换 `business01` → 审批中心 → 通过"合同签署审批： 入驻合同 测试养鸡场"
4. 换 `finance01` → 审批中心 → 通过同一条的第二级"财务审批"
5. 换 `testfarm01` → 合同管理 → 点该合同右侧"查看"
6. ✅ **预期**：新标签页打开合同原文，能看到甲方（蛋品交易平台运营方）、乙方（测试养鸡场）、交易规则条款
7. 回到合同管理，换 `business01` 登录 → 点"在线签署" → 弹窗点"确认"
8. ✅ **预期**：提示"签署成功，待另一方签署"，"双方签署"列平台方打勾
9. 换 `testfarm01` 登录 → 同一合同点"在线签署"
10. ✅ **预期**：提示"双方签署完成，合同生效并存证"，状态变"已生效"，双方都打勾

# 流程二：建仓入库

**目标：验证 仓库登记 → 租赁审批 → 监控确权 → 产蛋录入 → 交割仓建立 → 自动上架 全链路**

### 2.1 养殖户登记仓库

1. 用 `farm001 / 123456` 登录
2. 左侧"我的仓库" → 右上角"登记仓库"
3. 填写：仓库名称 `测试2号仓`、地址 `郑州市中牟县万滩镇`、容量 `3000`
4. 点"提交"
5. ✅ **预期**：列表出现"测试2号仓"，租赁状态"未租赁"，监控"未确权"

### 2.2 业务端发起租赁审批（两级）

1. 换 `business01` → 左侧"仓库管理"
2. 找到"测试2号仓"，点"发起租赁审批"
3. 弹窗中租金填 `6000` → 点"发起审批"
4. ✅ **预期**：提示"租赁审批已发起（业务→财务两级审批）"
5. 点"审批中心" → 通过"仓库租赁审批： 测试2号仓"（这是第一级）
6. 换 `finance01` → 审批中心 → 通过同一条（第二级）
7. ✅ **预期**：回到 business01 的"仓库管理"，该仓库租赁状态变"已租赁"，显示租金 6000

### 2.3 监控设备接入与确权

1. 换 `farm001` → 我的仓库 → "测试2号仓"行点"监控设备"
2. 弹窗中点"登记设备"，填写：设备名称 `2号仓东门摄像头`、协议选 `RTSP`、流地址填 `rtsp://192.168.1.200:554/ch1` → 确定
3. 设备列表里点该设备的"在线检测"
4. ✅ **预期**：提示"检测完成：设备在线（模拟）"，在线列变绿色"在线"
5. 换 `business01` → 仓库管理 → "测试2号仓"点"设备管理" → 对该设备点"确权"
6. ✅ **预期**：提示"确权完成，仓库监控已标记在线"，仓库"监控"列变绿色"已确权"

### 2.4 产蛋数据录入

1. 换 `farm001` → 左侧"产蛋录入" → "录入产蛋数据"
2. 日期选今天、数量 `3000`、品级 `A级`、规格 `50kg/件` → 提交
3. ✅ **预期**：列表出现这条记录

### 2.5 建交割仓（含定价）

1. 换 `business01` → 仓库管理 → "测试2号仓"点"建交割仓"
2. 填写：数量 `3000`、品级 `A`、规格 `S50`、**单价 `5.5`** → 发起审批
3. 审批中心 → 通过"交割仓建立审批"
4. ✅ **预期**：提示审批完成

### 2.6 验证交割仓与库存

1. 换 `farm001` → 交割仓一览
2. ✅ **预期**：看到 DW 开头的交割仓：数量 3000、A 级、状态"在库"、在库 0 天
3. 左侧"库存查询"
4. ✅ **预期**：测试2号仓 A 级：总库存 3000、锁定 0、可用 3000

### 2.7 验证自动上架与货架管理

1. 换 `buyer001` → 商品大厅
2. ✅ **预期**：出现商品卡片"鸡蛋 A级"，价格 ¥5.5，库存 3000，来源"绿源蛋鸡养殖场"
3. 换 `business01` → 货架管理 → 对该商品点"改价" → 输入 `5.8` → 确定
4. 再点"下架"
5. 换 `buyer001` 刷新商品大厅
6. ✅ **预期**：该商品消失
7. 回 business01 再点"上架" → buyer001 刷新
8. ✅ **预期**：商品回来了，价格变为 ¥5.8

# 流程三：模式①完整交易（核心）

**目标：完整走一遍"下单→审核→定金→垫资→出库三确→尾款→结算→二维码→核销放行"，并核对金额与库存**

> 继续用流程二上架的商品（A 级、¥5.8、库存 3000）。**全程注意观察订单详情的"流转记录"时间线。**

### 3.1 采购商下单

1. 用 `buyer001 / 123456` 登录 → 商品大厅
2. 找到 A 级鸡蛋卡片，点"采购"
3. 弹窗中：采购数量 `1000`、销售模式选"①蛋库出库标准"
4. 核对页面显示"预估总额 ¥5800（定金 20% = ¥1160）"
5. 点"提交采购订单"
6. ✅ **预期**：提示"待业务审核"，自动跳到订单详情页，状态"业务审核中"

### 3.2 业务审核订单

1. 换 `business01` → 审批中心 → 通过"订单审核： SO…"
2. ✅ **预期**：订单状态变"待付定金"
3. 换 `farm001` → 合同管理
4. ✅ **预期**：多一份**销售合同**（系统自动生成，关联本订单）

### 3.3 客户支付定金（并核对库存锁定）

1. 换 `buyer001` → 订单管理 → 点进该订单 → 点"支付定金 ¥1160" → 确认
2. ✅ **预期**：提示"支付成功"，状态变"定金已付（垫资审批中）"
3. 换 `farm001` → 库存查询
4. ✅ **预期**：总库存 3000、**锁定 1000**、可用 2000

### 3.4 财务垫资审批（80% 给养殖户）

1. 换 `finance01` → 审批中心 → 通过"垫资审批（80%): SO…"
2. ✅ **预期**：订单状态变"平台已垫资80%"
3. 换 `farm001` → 看站内信（消息）
4. ✅ **预期**：有"垫资到账： SO… ¥4640"通知

### 3.5 业务开具出库单

1. 换 `business01` → 订单管理 → 点进该订单 → 点"开具出库单"
2. 填写：车牌号 `豫A12345`、司机姓名 `王五`、司机电话 `13700000003` → 开具
3. ✅ **预期**：状态变"装车核验中"，页面出现出库单区块，三方确认标签都是灰色
4. 点"上传照片/视频（自动水印）" → 选一张图片
5. ✅ **预期**：附件区出现"照片（已水印）"标签

### 3.6 三方确认出库单（重点：需要三个角色分别操作）

1. 换 `farm001` → 订单详情 → 点"养殖户确认"
2. ✅ **预期**："养殖户"标签变绿，提示"确认成功，待其他方确认"
3. 换 `buyer001` → 订单详情 → 点"客户确认" → "客户"标签变绿
4. 换 `business01` → 订单详情 → 点"平台确认"
5. ✅ **预期**：三个标签全绿，状态变"出库单已确认"

### 3.7 客户支付尾款

1. 换 `buyer001` → 订单详情 → 点"支付尾款 ¥4640" → 确认
2. ✅ **预期**：状态变"尾款已付（结算审批中）"

### 3.8 财务尾款结算审批（20% 给养殖户）

1. 换 `finance01` → 审批中心 → 通过"尾款结算审批（20%): SO…"
2. ✅ **预期**：状态变"养殖户已收全款（待放行）"
3. farm001 站内信收到"尾款到账"通知

### 3.9 电子提货凭证与核销放行

1. 换 `farm001` → 订单详情
2. ✅ **预期**：出现"电子提货凭证"卡片，左侧是二维码，右侧一串 `EGGPICKUP:PV…` 文字
3. 选中那串文字并复制（Command+C）
4. 粘贴到下方输入框（Command+V）→ 点红色"核销放行"按钮
5. ✅ **预期**：提示"核销成功，放行！"，订单状态变"已完成"，凭证状态变"已核销"

### 3.10 防重复核销验证

1. 同一页面再点一次"核销放行"
2. ✅ **预期**：提示"该凭证已核销，请勿重复操作"

### 3.11 核对最终结果（三项都要对）

1. farm001 → 库存查询：✅ **库存 2000、锁定 0**（3000-1000）
2. finance01 → 账单中心：✅ 该订单账单"已结清"
3. business01 → 订单详情 → 底部"资金流水"：✅ 4 笔——收定金 1160、收尾款 4640、付垫资 4640、付结算 1160（收付相等都是 5800）
4. farm001 → 交割仓一览：✅ 该交割仓状态"已售"
