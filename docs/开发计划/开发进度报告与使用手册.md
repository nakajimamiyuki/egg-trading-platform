## 1. 通用操作

### 1.1 注册（养殖企业 / 采购商）
1. 打开 http://localhost:8080 → 点"企业自助注册"
2. 选择企业类型，填写账号信息（用户名/密码/联系人/手机号）
3. 填写企业信息；养殖企业额外填：养殖品种、存栏量、日龄、日均产蛋量
4. 上传证照（养殖企业：营业执照/法人身份证/养殖许可证/引种证明；采购商：营业执照/法人身份证）
5. 提交后等待平台审核（审核结果会发站内信，首页和"我的企业"可见状态）

### 1.2 审批（业务/财务）
1. 左侧"审批中心"看到待办列表
2. 点"通过/驳回"，可填审批意见
3. 审批通过后系统自动执行后续动作（建仓、付款、开合同等），无需人工再操作

### 1.3 消息
页面右上角/消息列表查看站内信：准入结果、垫资到账、尾款到账、平仓预警等。

## 2. 养殖端操作手册（farm001）

### 2.1 建仓入库流程
1. **我的仓库 → 登记仓库**：填名称/地址/容量 → 等待平台业务员发起租赁审批
2. **我的仓库 → 监控设备**：登记摄像头（协议 RTSP/GB28181 + 流地址）→ 点"在线检测"→ 等业务端确权 → 可上传监控点位图
3. **产蛋录入**：选日期，填数量/品级/规格
4. 等业务端发起交割仓审批并通过后，在**交割仓一览**可见（含在库天数与周转预警标识）

### 2.2 销售
- **交割仓一览 → 发起销售申请**（在库状态的交割仓）
- 或在业务端定价上架后，等客户在商品大厅下单
- 订单进行中可在**订单管理 → 订单详情**查看进度（状态时间线）
- 养殖户收到全款后，订单详情出现**电子提货凭证二维码** → 客户/司机来提货时，扫码（或粘贴二维码内容）点"核销放行" → 库存自动扣减

### 2.3 平仓与申请
- **平仓风控**页看到周转预警（在库 ≥3 天标红）
- 可发起五类申请：退仓 / 平台自行销售（指定客户）/ 平台自行销售（非指定客户）/ 销售给平台 / 超期订单处理
- 退仓审批通过后：货物库存退回，交割仓关闭

### 2.4 财务相关
- **账单中心**：每单应收/已收、结清状态
- **合同管理**：入驻合同（首次入驻时签一次）、每单销售合同；点"在线签署"完成签署，"查看"打开合同原文
- **合作激励**：查看自己的合作月数与累计发货量达标进度

## 3. 客户端操作手册（buyer001）

### 3.1 采购全流程（模式①示例）
1. **商品大厅**：浏览现货（品级/规格/来源养殖户/价格/库存），可按"指定/非指定养殖户"和品级筛选
2. 点"采购" → 填数量、选销售模式（①蛋库出库 ②在途预付 ③渠道账期）→ 提交（可看到定金 20% 预估）
3. 等业务审核通过 → **订单详情 → 支付定金**（当前为模拟支付）
4. 等平台垫资、装车核验 → 出库单三方确认（你作为客户点"客户确认"）
5. **支付尾款**（80%）
6. 平台结算给养殖户后，安排提货
7. **订单管理**随时看进度；**发票管理 → 申请开票**（订单付款完成后）
8. **合同管理**查看/签署销售合同

## 4. 业务端操作手册（business01）

### 4.1 日常工作台
- **审批中心**：准入/租赁/交割仓/订单/合同等所有待办审批
- **合作方管理**：养殖户/采购商列表，按类型和状态筛选
- **仓库管理**：发起租赁审批（填租金）→ 设备管理（确权）→ 建交割仓（填数量/品级/规格/**定价**）
- **货架管理**：改价、上下架
- **订单管理**：点订单进详情 → 垫资完成后"开具出库单"（车牌/司机）→ 装车后"平台确认" → 可"登记运单"并更新物流轨迹

### 4.2 风控
- **平仓风控**：预警列表 → "强制平仓"（按折价比例结算，默认 80%，管理员可在参数配置调整）
- **渠道尽调**：为渠道客户（如京东）登记尽调结论（通过/不通过）+ 上传评价报告
- **合作激励**：查看养殖户达标进度，达标后"确认赠送"

### 4.3 对账与看板
- **对账中心**：选范围和区间"发起对账" → 系统自动匹配订单与资金流水 → 有差异时财务调账 → 确认归档
- **数据看板**：收/付/退汇总卡片、模式分布饼图、每日交易额折线、"导出 Excel 交易报表"

## 5. 财务端操作手册（finance01）

- **审批中心**：垫资 80%、尾款结算 20%、平仓退款、发票审批
- **付款执行**：当 `bank_channel=MANUAL` 时，审批通过的付款在此上传银行回单并"确认到账"
- **发票管理**：审批（审批中心）→ 自动开具 → 归档；任何端可"发票查验"
- **渠道尽调**：风控团队登记尽调结论（模式③的前置条件）
- **对账中心 / 数据看板**：同业务端

## 8. 常见问题

- **合同链接打不开**：已在 M4 修复（预签名 URL 改用公网地址），如再遇到先 `docker compose restart backend`
- **改了建库 SQL 不生效**：SQL 只在空数据卷首次启动时执行，需 `docker compose down -v` 重置后重启
- **页面空白/接口 401**：退出重新登录即可（JWT 默认 12 小时过期）
- **80 端口打不开**：前端在 8080 端口（80 被本机其他项目占用）
