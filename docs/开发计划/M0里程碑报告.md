## 1. 本阶段交付内容

### 1.1 Docker Compose 一键开发环境

`docker-compose.yml` 一套编排 6 个容器：

| 容器 | 镜像 | 端口 | 用途 |
|---|---|---|---|
| egg-postgres | postgres:15 | 5432 | 主数据库，数据卷持久化 |
| egg-redis | redis:7 | 6379 | Session/缓存/库存锁（预留） |
| egg-rabbitmq | rabbitmq:3.13-management | 5672 / 15672 | 消息队列 + 管理台 |
| egg-minio | minio/minio | 9000 / 9001 | 文件存储（证照/合同/出库照片）+ 控制台 |
| egg-backend | 本地构建 python:3.12-slim | 8000 | FastAPI，源码挂载热更新 |
| egg-frontend | 本地构建 node:20→nginx | **8080** | Vue3 产物 + /api 反向代理 |

> 端口说明：本机 80 端口被 ragflow 项目占用，前端改用 8080。

### 1.2 数据库完整建库 SQL

`docker/postgres/init/01_schema.sql`，首次启动自动执行，**42 张表**全部创建成功：

- 系统权限：sys_role / sys_permission / sys_user / sys_user_role / sys_role_permission
- 企业准入：enterprise（含养殖专属字段）、enterprise_file
- 字典：sys_dict_type / sys_dict_item（品级 A/B/C、规格 50/45/40kg 已入种子）
- 审批流引擎：wf_definition / wf_node / wf_instance / wf_task
- 文件：file_record（MinIO 对象索引）
- 仓储库存：warehouse / egg_production / delivery_warehouse / inventory（乐观锁+锁定量）/ inventory_log
- IoT：iot_device
- 商品货架：product / shelf_item
- 订单：order_info（三种模式、定金/垫资比例、账期、分利字段）/ order_item / order_event
- 资金：pay_record（统一收付流水，MOCK/微信/支付宝/银企直联/人工五通道）/ finance_bill
- 交付：outbound_order（三方确认）/ outbound_file / pickup_voucher（核销凭证）
- 合同发票：contract_template / contract / invoice
- 风控平仓：risk_survey / close_apply（5 类申请）/ close_order（折价处置）
- 对账：reconcile_batch / reconcile_diff（调账留痕）
- 物流：logistics_order / logistics_track
- 消息：message ｜ 激励：incentive_record

### 1.3 FastAPI 后端骨架

`backend/app/`：core（配置/统一返回 `{"code":0,"message","data"}`/全局异常/JWT 工具）→ database（异步会话）→ api（路由聚合）→ modules（20 个业务模块包已建，M1 起填充）。含单元测试（pytest 冒烟通过）。

### 1.4 Vue3 前端骨架

`frontend/src/`：Vite + TS + Pinia + Vue Router + Element Plus（中文）+ Axios 封装（Token 自动注入/统一错误处理）+ 权限路由守卫占位 + M0 验证页。
