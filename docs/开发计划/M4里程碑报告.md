## 1. 交付功能

### 电子合同（生成→审批→双签→归档）
- **入驻合同**：企业准入审批通过时**自动生成**（仅首次入驻，F3.2 确认规则），内容含平台交易规则与平仓条款（折价比例、周转天数从 sys_config 实时读取）
- **销售合同**：订单业务审核通过时自动生成，含标的物/金额/销售模式
- 合同以 HTML 存证 MinIO，页面可在线查看原文
- 签署流程：CONTRACT_SIGN 审批（业务→财务两级）→ 双方在线签署（甲方=平台人员，乙方=企业用户）→ SIGNED 生效 → 平台归档
- e签宝/法大大接入点已预留（esign_flow_id 字段 + 签署状态机可直接对接沙箱）

### 电子发票（申请→审批→开具→查验→归档）
- 客户在订单付款完成后申请开票（抬头/税号），重复申请拦截
- 财务审批（INVOICE_AUDIT）通过自动开具发票号
- 发票查验（当前与平台记录核对的模拟查验，接服务商后替换）
- 财务归档入账

### 银企直联兜底通道（F9.7）
- 新增参数 `bank_channel`：`MOCK`（自动到账，默认）/ `MANUAL`（人工转账）
- MANUAL 模式下：垫资/尾款审批通过 → 生成待确认流水 → 财务在"付款执行"页上传银行回单 → 确认到账后才生效（触发凭证生成/账单结清）
- 真实银企直联签约后只需增加 BANK 通道适配器，业务代码零改动

### 消息联动（F9.5 首批）
- 准入审批结果、垫资到账、尾款到账 → 自动站内信到对应企业用户

## 3. 页面入口

- 合同管理：所有端左侧菜单"合同管理"（查看/签署/归档）
- 发票管理：客户端申请开票，财务端审批（审批中心）+ 归档；任何端可查验
- 付款执行：财务端（MANUAL 模式时启用；管理员在参数配置把 bank_channel 改为 MANUAL 即可体验）
