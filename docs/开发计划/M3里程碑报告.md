## 1. 订单状态机（核心资产）

```
CREATE 建单 → AUDIT 业务审核 → DEPOSIT_PENDING 待付定金
→ DEPOSIT_PAID 定金20%已付(锁库存) → ADVANCE_PAID 财务审批垫资80%给养殖户
→ VERIFYING 出库单待三方确认 → OUTBOUND_CONFIRMED → TAIL_PAID 客户付80%尾款
→ FULL_PAID 财务审批结算20%(模式③内扣分利) → 自动生成核销二维码
→ RELEASED 养殖户扫码放行(库存实时扣减) → FINISHED
```

每一步状态流转都写 `order_event` 留痕，订单详情页有时间线。

## 2. 交付清单

### 后端
- 货架：交割仓审批通过**自动上架**（业务端建仓时定价，符合已确认规则）；改价/上下架
- 采购建单：数量校验、定金/垫资金额按 sys_config 比例自动计算、模式③账期+分利计算
- 资金服务：统一 `pay_record` 流水（收/付、五类款项）、账单中心自动记账结清
- 审批回调：ORDER_AUDIT / PAYMENT_80 / PAYMENT_20 / SALE_APPLY 全自动驱动状态机
- 出库单：车牌/司机、照片视频附件（水印标记）、三方确认（养殖户/客户/平台各自确认，全部确认才放行尾款）
- 核销凭证：HMAC 签名防伪造；**幂等**（重复扫码明确提示）；仅卖方养殖户可核销；放行即扣库存
- 库存：定金锁定(LOCK) → 核销扣减(OUT)，全程流水可查

### 前端（8 个新页面/区块）
- 商品大厅（客户端）：卡片式货架、品级/指定筛选、三种模式下单弹窗（实时算定金）
- 订单详情：状态时间线 + 按角色/状态显示操作按钮（付定金、付尾款、开出库单、三方确认、上传水印照片、展示/扫描二维码、核销放行）+ 资金流水表
- 订单管理、货架管理（业务）、账单中心（四端）

### 安全与风控验证（已实测）
- 客户扫码核销被拒（仅卖方有权放行）✅
- 重复扫码被拒（幂等）✅

- 资金四笔流水核对：收定金 ¥1100 + 收尾款 ¥4400 = 付垫资 ¥4400 + 付结算 ¥1100 ✅
