## 2. 页面入口（http://localhost:8080）

- **平仓风控**（养殖/业务/财务）：预警列表、发起五类申请、强制平仓按钮、申请记录、平仓台账
- **渠道尽调**（业务/财务）：登记尽调结论、上传评价报告
- **对账中心**（业务/财务）：发起对账、差异明细、调账、归档
- **数据看板**（业务/财务）：统计卡片 + 图表 + Excel 导出
- **合作激励**（养殖/业务）：达标进度与赠送确认
- **订单详情**：物流区块（登记运单、轨迹更新、轨迹时间线）

## 4. 已知简化（M6 或运营期处理）

- 周转预警为每日定时 + 手动；如需更实时可改为小时级
- 强制平仓当前由业务端手动触发（预警后督办），如需"超期自动平仓"可在调度器开启
- 模式③分利按"元/件"×数量计算，需求中"件"与"枚"的换算规则待业务方明确（当前 1 枚=1 件）
- 运满满/GPS 为人工兜底模式，接口到位后切换自动回传
- 自营业务（业务端自营采购/销售）复用同一订单状态机，self_operated 标记已实现，页面在 M6 视反馈补充
