## 1. 交付功能

### 养殖端
- **我的仓库**：登记仓库（名称/地址/容量），查看租赁状态、监控确权状态，管理监控设备
- **产蛋录入**：按日期录入数量/品级/规格（字典下拉）
- **交割仓一览**：编号、在库天数、**周转预警标识**（≥3 天自动标红，为 M5 平仓预警打底）
- **库存查询**：总库存/锁定/可用（仅本企业数据）

### 业务端
- **仓库管理**：全部仓库列表，发起**租赁审批**（租金条款）→ 业务→财务两级审批 → 自动回写"已租赁"
- **设备管理**：登记摄像头（RTSP/GB28181）、在线检测（当前模拟实现）、**确权**、上传监控点位图
- **建交割仓**：前置校验（必须已租赁 + 监控已确权，否则拒绝），发起交割仓审批 → 通过后**自动建立交割仓 + 库存初始化 + 库存流水**

### 后端能力（供后续里程碑复用）
- 审批流引擎新增 2 个回调：WAREHOUSE_LEASE、DELIVERY_WH_CREATE
- 库存服务 `change_inventory()`：乐观锁 + 全量流水，M3 定金锁定/M5 出库扣减直接复用
- `dw_no` 编号规则：DW+日期+序号；周转天数读取 sys_config（管理员可改）

## 2. 验证结果（实测通过）

完整链路：注册养殖户 → 准入通过 → 登记仓库 → 租赁两级审批通过 → 设备登记→检测→确权 → 产蛋录入 → 交割仓审批通过 → `DW202608130001 IN_STOCK 3000枚` → 库存 3000 枚 + INIT 流水

防呆校验也已验证：监控未确权时发起交割仓审批会被拒绝（400 提示）。
